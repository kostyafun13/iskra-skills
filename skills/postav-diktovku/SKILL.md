# Поставить Диктовку

**Результат:** значок микрофона в строке меню Мака. Говоришь вместо того, чтобы печатать, — в Claude, Codex, Telegram, почте, где угодно. Выделенный текст Мак читает вслух. Всё надиктованное хранится на твоём Маке.

## Что умеет — все клавиши ПРАВЫЕ
| Жест | Что делает |
|---|---|
| ⌘ зажат | диктовка: говоришь, отпустил — текст встаёт в поле под курсором |
| ⌘ дольше 3 с | запись без пальца; стоп — ещё раз правый ⌘. Клавиатура на это время заперта, ⌘⇥ проходит |
| ⌥ (0,2 с) | вставить последнюю диктовку ещё раз; сразу ещё ⌥ — предпоследнюю |
| ⌥ (держать 0,5 с) | буфер: 4 последние диктовки; ⇧ + клик — собрать несколько по порядку |
| ⇧ (0,2 с) | прочитать выделенное вслух; ещё раз ⇧ — стоп; ←/→ — скорость, ↑/↓ — ±15 с |
| Ю (держать 0,5 с) | запомнить выделенное слово как термин |
| Б (держать 0,5 с) | включить или выключить Bluetooth |
| ⌥ + ⇧ вместе | поправить грамматику выделенного ИИ — только на своём ключе, по умолчанию выключено |

Меню значка: «Не давать компьютеру уснуть» (зелёная точка на значке) · «🧹 Закрыть всё, кроме Клода, Кодекса, Хрома, Зума и Телеги» (VPN тоже не трогает) · история диктовок · записи звука за 7 дней · «что впечаталось в окно» · голос озвучки · режим распознавания · микрофон · «🔓 Оживить клавиатуру» · «🔄 Перезапустить Диктовку».

## Сколько стоит
- Распознавание облаком Яндекса — около 0,65 ₽ за минуту речи.
- Голос Яндекса — около 0,65 ₽ за 1000 знаков, страница текста — около 1,3 ₽.
- Системный голос macOS и локальная модель распознавания — бесплатно.
Точные тарифы — в консоли Яндекс Облака. Подписка Claude или ChatGPT этих расходов не покрывает.

## Первый запуск — бриф
Если в `PROFILE.md` нет раздела «Диктовка», до работы задай вопросы по одному. У каждого есть ответ по умолчанию — человек может сказать «по умолчанию». Ответы сохрани в `PROFILE.md`, раздел «Диктовка», и больше не спрашивай.
1. Чем распознавать речь? (по умолчанию — облако Яндекса: ставится за 5 минут. Ещё варианты: облако плюс локальная модель — +0,5 ГБ, короткое бесплатно, на длинном греет Мак; только локально — бесплатно, длинные диктовки отстают)
2. Каким голосом читать вслух? (по умолчанию — Яндекс, Алёна. Ещё Филипп, Джейн, Ермил, Захар или бесплатный системный голос)
3. Запускать Диктовку при входе в Мак? (по умолчанию — да)
4. Какие программы, кроме Claude, Codex, Chrome, Zoom, Telegram и VPN, не закрывать кнопкой «Закрыть всё»? (по умолчанию — никакие)
5. Какие слова распознаются криво: компания, продукты, имена? (по умолчанию — заполним по ходу)
6. Нужна ИИ-правка грамматики? (по умолчанию — нет; включается позже на своём ключе Claude API, это отдельный счёт)

## Порядок для ИИ
`SKILL_DIR` — папка этого скила: `~/.claude/skills/postav-diktovku` или `~/.codex/skills/postav-diktovku`.

**0. Проверь Мак.** `sw_vers -productVersion` — 13 или новее. `xcode-select -p` — путь есть. Нет → `xcode-select --install`, владелец жмёт «Установить» и ждёт 5–15 минут. Уже есть `~/Applications/Diktovka.app` → это обновление, раздел «Обновить».

**1. Ключ Яндекса** — если в брифе облако.
- Ключ заводит скил `podklyuchit-rasshifrovku`: файл `connections/rasshifrovka/.env`, строка `YANDEX_API_KEY`. Не подключено → сначала он.
- Голосу нужна ещё озвучка. Владелец в console.yandex.cloud: сервисный аккаунт → добавить роль `ai.speechkit-tts.user` → создать новый API-ключ с областями `yc.ai.speechkitStt.execute` и `yc.ai.speechkitTts.execute` → вписать его в тот же `.env` вместо прежнего (ИИ откроет файл) → прежний ключ удалить в консоли. Распознавание голосовых продолжит работать на новом ключе.
- Ключ не читай и не печатай. Проверка без показа: `grep -c '^YANDEX_API_KEY=.' <путь к .env>` → 1.

**2. Собери.** `bash "$SKILL_DIR/diktovka/build_app.sh"` → `~/Applications/Diktovka.app`, 1–3 минуты. Упала компиляция → покажи владельцу последние 20 строк вывода, исходники наугад не правь.

**3. Настрой.** Папка настроек — `~/Library/Application Support/Diktovka/`, создай её.
- `tts.json` — откуда брать ключ и каким голосом читать (`voice`: alena, filipp, jane, ermil, zahar):
  ```json
  {"env_file": "<абсолютный путь к connections/rasshifrovka/.env>", "env_var": "YANDEX_API_KEY", "voice": "alena", "api": "v3", "rub_per_1000": 0.65}
  ```
- `ostavit.txt` — программы из ответа 4, по строке: часть имени («Заметки») или начало бандла («com.apple.Notes»).
- `words.txt` создастся при первом запуске; слова из ответа 5 допиши строками `как_слышится=как_надо`.
- Проверка: `~/Applications/Diktovka.app/Contents/MacOS/Diktovka --proverka` → «✓ Ключ Яндекса найден» и «✓ Распознавание: …». Ключ команда не печатает.

**4. Локальная модель** — только если выбрана в брифе. Нужен python 3.10+ (`brew install python`). `bash "$SKILL_DIR/diktovka/install_engine.sh"` — 0,5 ГБ, 5–10 минут. «Только локально» → после установки `defaults write ru.iskra.diktovka asrRoute local`.

**5. Запусти и выдай разрешения.** `open ~/Applications/Diktovka.app` → в строке меню значок микрофона. Разрешения включает владелец, ИИ подсказывает по одному:
1. **Микрофон** — системное окно → «Разрешить».
2. **Универсальный доступ** — Диктовка сама откроет Настройки → Конфиденциальность и безопасность → Универсальный доступ: включить Diktovka. Нет в списке → «+» → ⌘⇧G → `~/Applications/Diktovka.app`. Пароль Мака вводит владелец.
3. **Мониторинг ввода** — если macOS спросит или жесты молчат: там же, раздел «Мониторинг ввода» → включить Diktovka.
4. **Bluetooth** — спросит только при первом зажатии Б.

Проверка: `grep "CGEventTap установлен" ~/Library/Application\ Support/Diktovka/app.log | tail -1` — строка со временем после запуска. Нет → меню значка → «Выдать разрешения…»; не помогло — в Универсальном доступе удалить строку Diktovka «−» и добавить заново «+».

**6. Автозапуск** — если «да» в брифе: `bash "$SKILL_DIR/diktovka/install_autostart.sh"`.

**7. Голос по брифу.** Системный голос → меню значка → «Голос озвучки» → выбрать. Яндекс уже включён через `tts.json`.

## Приёмка — вместе с владельцем, 5 минут
- Открой Заметки, зажми правый ⌘, скажи 2 фразы, отпусти → текст в заметке, в `app.log` строка «впечатано».
- Выдели абзац, правый ⇧ → читает голосом из брифа; ещё раз ⇧ — замолчал.
- Правый ⌥ → последняя диктовка вставилась ещё раз.
- Меню → «Не давать компьютеру уснуть» → зелёная точка на значке, `pmset -g assertions | grep -c Диктовка` больше 0. Владельцу не нужно — выключить.
- `--proverka` показывает, что закрыла бы кнопка «🧹 Закрыть всё…». Закрываются вежливо, как ⌘Q: несохранённое программа спросит сама.
- `~/Library/Application Support/Diktovka/history.txt` пополнился.
- Ответы брифа лежат в `PROFILE.md`.

Доклад владельцу — 5 строк: что поставлено, чем распознаём и каким голосом читаем, что проверено, что осталось.

## Обновить
`bash "$SKILL_DIR/diktovka/build_app.sh"`. Диктовка запущена → сборка ляжет рядом как `Diktovka.new.app`, меню → «🔄 Перезапустить Диктовку» её подменит. Подпись ad-hoc → после обновления Универсальный доступ выдать заново: «−», потом «+».

## Если что-то не так
- Клавиатура не печатает → меню значка → «🔓 Оживить клавиатуру». Мышь работает всегда.
- «📡 Слабый интернет — переспрашиваю» → сеть или VPN тормозят; недочитанный хвост дочитает системный голос.
- Жесты молчат после обновления → Универсальный доступ: «−», потом «+».
- Удалить: меню → «Выйти», `bash "$SKILL_DIR/diktovka/install_autostart.sh" --udalit`, удалить `~/Applications/Diktovka.app` и папку `~/Library/Application Support/Diktovka` — в ней история и записи.

## Что где лежит
- `~/Library/Application Support/Diktovka/`: `history.txt` — история диктовок, `raw_dictation.log` — всё распознанное, `zapisi/` — звук за 7 дней (старше чистится сам), `vstavki.jsonl` — что впечаталось в окно, `app.log` — журнал работы, `words.txt` и `terms.txt` — словарик, `ostavit.txt`, `tts.json`, `ai.json`.
- Наружу уходят только куски звука и текст для озвучки — в Яндекс по твоему ключу, и текст на правку — твоему ИИ-провайдеру, если ИИ-правка включена. Больше никуда.
- Исходники открыты: `diktovka/Sources`. ИИ может прочитать их перед сборкой.

## ИИ-правка грамматики — по желанию
Нужен свой ключ Claude API (console.anthropic.com, отдельный счёт). Ключ — строкой `ANTHROPIC_API_KEY=` в любом своём `.env`, не в чат. Файл `ai.json` в папке настроек:
```json
{"url": "https://api.anthropic.com/v1/messages", "model": "claude-haiku-5-5", "format": "anthropic", "env_file": "<абсолютный путь к .env>", "env_var": "ANTHROPIC_API_KEY"}
```
Затем меню → «🔄 Перезапустить Диктовку». Пункт «✨ Править каждую диктовку (ИИ)» станет доступен, жест ⌥ + ⇧ заработает.

## Самообучение
Поправка к результату («не так, надо вот так») — переделай результат и допиши правило в этот SKILL.md: что делать, почему, было → стало. Режим — из `PROFILE.md`, раздел «Режим обновления скилов»: «сам» — обнови и скажи одной строкой; «спрашивать» — предложи правку и обнови после «да»; «после серии» — копи правки и предложи пакетом. Режима в профиле нет — спроси один раз. Перед свёрткой проверь, что все правки чата легли в скилы.
