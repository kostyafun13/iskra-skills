# Топ-15 с интро

**Результат:** таблица до 15 человек под запрос адресата + общее интро адресата + адресные интро для выбранных.

## Первый запуск — бриф
Если в `PROFILE.md` нет раздела «Топ-15 с интро», до работы задай вопросы по одному. У каждого есть вариант по умолчанию — человек может ответить «по умолчанию». Ответы сохрани в `PROFILE.md` в раздел «Топ-15 с интро» и больше не спрашивай.
1. Где лежит твой соцактив: Telegram, таблица, CRM? (по умолчанию — Telegram)
2. Кому даём подборки? (по умолчанию — тем, кто делает такую же для тебя)
3. Кого считаем тёплым? (по умолчанию — ответил за 30 дней)

## Порядок
1. **Профиль адресата** по 5 блокам: оффер → для кого → кейсы → кто нужен → кто есть. Берётся из его слов и материалов. Неизвестное — вопросом к нему.
2. **Поиск по соцактиву владельца:** профили, био, личка, группы, расшифровки встреч. Сначала конкретное совпадение с запросом, потом доказанность доступа, потом масштаб.
3. **Приватный реестр:** все рассмотренные кандидаты с основанием доступа и источником. Остаётся у владельца.
4. **Внешний топ:** до 15 строк — имя, компания, роль, польза адресату, теплота (горячий — встречались; тёплый — общаемся). **Без контактов.** Холодных не включать.
5. **Интро:** общее интро адресата одним файлом; адресные интро — для тех, кого адресат выбрал.

## Правило обмена
Подборку делаем тому, кто делает такую же для владельца по своей базе. Это основная разменная монета.

## Приёмка
Каждая строка топа имеет основание в источнике; пригодных меньше 15 — выдать меньше и сказать почему; пакет не отправляется без «да» владельца.

## Самообучение
Поправка к результату («не так, надо вот так») — переделай результат и допиши правило в этот SKILL.md: что делать, почему, было → стало. Режим — из `PROFILE.md`, раздел «Режим обновления скилов»: «сам» — обнови и скажи одной строкой; «спрашивать» — предложи правку и обнови после «да»; «после серии» — копи правки и предложи пакетом. Режима в профиле нет — спроси один раз. Перед свёрткой проверь, что все правки чата легли в скилы.
