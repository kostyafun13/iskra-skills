# Подключить Google Документы

**Зачем:** материалы, итоги и письма ИИ кладёт в Google Документы и сразу даёт ссылку — человеку не нужно скачивать файлы.

## Почему вход своим аккаунтом, а не сервисный аккаунт
Сервисный аккаунт не может создавать файлы в личном Google Диске: своего места у него нет, Google отвечает ошибкой квоты. Он работает только с общим диском Google Workspace — это платная почта на своём домене. Поэтому основной путь — вход своим аккаунтом.

## Что делает владелец — один раз, около 15 минут
1. console.cloud.google.com → создать проект, например «ИИ документы».
2. APIs & Services → Library → включить **Google Drive API**.
3. Экран согласия (OAuth consent screen, в новом интерфейсе — Google Auth Platform): тип **External**, название приложения, своя почта. Затем **Publish app** — статус In production. Почему: в статусе Testing вход слетает каждые 7 дней. С правом `drive.file` проверка Google для публикации не нужна.
4. Clients → Create client → **Desktop app** → скачать JSON → ИИ положит его в `connections/google/client_secret.json`.
5. Выполнить вход, который даст ИИ: откроется браузер, войти своим аккаунтом. Если Google напишет, что приложение не проверено — это ваше же приложение: «Дополнительно» → «Перейти».

## Что делает ИИ
1. Копирует `scripts/` в `connections/google/`, ставит окружение: `python3 -m venv .venv` и `.venv/bin/pip install -r requirements.txt`.
2. Ведёт владельца по шагам 1–5. Вход: `.venv/bin/python google_app.py login`.
3. Проверяет: `status` → почта владельца.
4. Заводит рабочую папку: `folder --name "ИИ — документы"`. Ссылку записывает в `PROFILE.md`, раздел «Подключения».
5. Документ из файла: `create --file итоги.md --folder <ссылка папки>`. Таблица — из `.csv` или `.xlsx`.
6. Ссылку «по ссылке» делает, только когда документ уходит человеку: `--share reader` (читать), `commenter` (комментировать), `writer` (править). По умолчанию доступ только у владельца.
7. Читает документ обратно: `read --file <ссылка> --out private/doc.txt`.

## Чужие документы
Право `drive.file` видит только то, что скрипт создал сам. Нужно прочитать существующий документ — владелец открывает его «всем, у кого есть ссылка», и ИИ читает текст по адресу `https://docs.google.com/document/d/<id>/export?format=txt`. Другой путь — встроенное подключение Google Drive в вашем ИИ, если оно есть.

## Проверка — подключено, когда
- `status` показал почту владельца;
- тестовый документ создан в рабочей папке и открывается по ссылке в окне инкогнито;
- `read` этого документа вернул текст;
- `.gitignore` закрывает `client_secret.json`, `token.json` и `private/`.

## Самообучение
Поправка к результату («не так, надо вот так») — переделай результат и допиши правило в этот SKILL.md: что делать, почему, было → стало. Режим — из `PROFILE.md`, раздел «Режим обновления скилов»: «сам» — обнови и скажи одной строкой; «спрашивать» — предложи правку и обнови после «да»; «после серии» — копи правки и предложи пакетом. Режима в профиле нет — спроси один раз. Перед свёрткой проверь, что все правки чата легли в скилы.
