# Аутрич

**Результат:** каждый день — новые встречи с нужными людьми, ни один ответ не потерян.

## Первый запуск — бриф
Если в `PROFILE.md` нет раздела «Аутрич», до работы задай вопросы по одному. У каждого есть вариант по умолчанию — человек может ответить «по умолчанию». Ответы сохрани в `PROFILE.md` в раздел «Аутрич» и больше не спрашивай.
1. Кто тебе нужен: роль, сфера, масштаб? (по умолчанию — возьму из целей на 90 дней)
2. В каких чатах искать? (по умолчанию — чаты, где ты уже состоишь)
3. Пришли свой заход-образец или скрипт. (по умолчанию — первая строка — польза человеку)
4. Сколько сообщений в день максимум? (по умолчанию — до 50)
5. Ссылка на встречу и удобные окна? (по умолчанию — спрошу при первой встрече)
6. Отправлять самому или после твоего „да“? (по умолчанию — после твоего „да“)

## Порядок (раз в день, отдельный чат)
1. **Скан:** собери людей из чатов, указанных владельцем, по его портрету (роль, сфера, масштаб).
2. **Проверка соответствия:** человек подходит под цели на 90 дней из `PROFILE.md`? Нет — пропусти.
3. **Заход:** персональное первое сообщение по скриптам владельца. Первая строка — польза человеку или факт о нём его же словами. Цель первого сообщения — получить ответ, а не продать.
4. **Отправка** — в пределах разрешения владельца и дневного лимита аккаунта (ориентир — до 50 личных сообщений в день, пачками по 25 с перерывом).
5. **Ответы:** на интерес — подробности и предложение встречи; сначала календарь, потом время; ссылка на встречу — в том же сообщении.
6. **Журнал:** человек · откуда · заход · ответ · встреча.

## Чистый контекст
Чат аутрича пересоздавай каждый день (скил `peresozdat-chat`): новый чат подхватывает всех, кто ответил на прошлые заходы.

## Приёмка
Число отправленных, ответивших и назначенных встреч за день — из журнала, а не по памяти.

## Границы
Письма людям — только по скрипту, который владелец одобрил. Не спамить: человек сказал «не надо» — больше не пишем.

## Самообучение
Поправка к результату («не так, надо вот так») — переделай результат и допиши правило в этот SKILL.md: что делать, почему, было → стало. Режим — из `PROFILE.md`, раздел «Режим обновления скилов»: «сам» — обнови и скажи одной строкой; «спрашивать» — предложи правку и обнови после «да»; «после серии» — копи правки и предложи пакетом. Режима в профиле нет — спроси один раз. Перед свёрткой проверь, что все правки чата легли в скилы.
