# Аутрич

**Результат:** каждый день — новые встречи с нужными людьми, ни один ответ не потерян.

## Порядок (раз в день, отдельный чат)
1. **Скан:** собери людей из чатов, указанных владельцем, по его портрету (роль, сфера, масштаб).
2. **Проверка соответствия:** человек подходит под цели на 90 дней из `PROFILE.md`? Нет — пропусти.
3. **Заход:** персональное первое сообщение по скриптам владельца. Первая строка — польза человеку или факт о нём его же словами. Цель первого сообщения — получить ответ, а не продать.
4. **Отправка** — в пределах разрешения владельца и дневного лимита аккаунта (ориентир — до 50 личных сообщений в день, пачками по 25 с перерывом).
5. **Ответы:** на интерес — подробности и предложение встречи; сначала календарь, потом время; ссылка на встречу — в том же сообщении.
6. **Журнал:** человек · откуда · заход · ответ · встреча.

## Чистый контекст
Чат аутрича пересоздавай каждый день (скил `peresozdat-chat`): новый чат подхватывает всех, кто ответил на прошлые заходы.

## Приёмка
Число отправленных, ответивших и назначенных встреч за день — из журнала, а не по памяти.

## Границы
Письма людям — только по скрипту, который владелец одобрил. Не спамить: человек сказал «не надо» — больше не пишем.
