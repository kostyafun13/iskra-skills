# Подборка топ-3

**Результат:** подборка для партнёра — 3 живые встречи, которые он сам захочет. Его интро по 5 пунктам, по каждому из троих — интро по 5 пунктам и точка пересечения с ним, подтверждённая словами на созвоне с тайм-кодом. В конце — вопрос «ставим встречи со всеми?».

**Зачем:** это разменная монета обмена выходами на топ-ЛПР. Подборки идут от узкого к широкому: **топ-3** из живых созвонов → **топ-15 с интро** (скил `top15-intro`) → **вся база** (скил `indeks-bazy`). *(Порядок заменён 11.11.2026 — см. «Сценарии подборок».)*

## Нужно до начала
Подключённые Zoom и расшифровка — источник созвонов (скилы `podklyuchit-zoom`, `podklyuchit-rasshifrovku`); Telegram — для теплоты и переписки (`podklyuchit-telegram`).

## Первый запуск — бриф
Если в `PROFILE.md` нет раздела «Подборка топ-3», до работы задай вопросы по одному. У каждого есть вариант по умолчанию — человек может ответить «по умолчанию». Ответы сохрани в `PROFILE.md` в раздел «Подборка топ-3» и больше не спрашивай.
1. За какой срок брать созвоны? (по умолчанию — за квартал)
2. В каком виде отдавать подборку: дека или одно сообщение? (по умолчанию — дека)
3. Кого не предлагать: конкуренты, чёрный список, личное? (по умолчанию — спрошу, когда увижу)

## Порядок
0. **Что уже есть** — реестр созвонов, готовые расшифровки, интро. Ничего не качаем и не расшифровываем повторно.
1. **Реестр квартала** — все созвоны владельца за период: человек → расшифровка → интро по 5 пунктам → тир. Реестр общий, следующая подборка берёт его готовым.
2. **Интро адресата по 5 пунктам** — оффер, для кого, подтверждённые кейсы, кто нужен, что даёт взамен. Из его слов на созвоне, с тайм-кодами. Чего не назвал — так и пишем: «не называл — обсудим на встрече».
3. **Отбор топ-3:**
   - **сначала — чем адресат зарабатывает.** Дорогой чек, B2B — крупные партнёры и ЛПР. B2C или дешёвая подписка — маяки, у кого уже сидят его клиенты, и джокеры, у кого его маяки; цепочка читается «джокер → маяк → клиент». Маяк — от 0,1% рынка клиентов адресата, меньше — микро-маяк;
   - **совпадения по интро:** «кто нужен» адресата ↔ «оффер» и «для кого» человека, и наоборот. Каждое совпадение — с причиной и источником;
   - **тиры по выручке:** тир 1 — от 20 млн ₽ в год, тир 2 — 5–20 млн, меньше 5 — первыми не идут. Свежий второй тир — недавний живой разговор и явный встречный интерес — бывает лучше первого;
   - **исключения — фактом:** чёрный список, знакомство уже было или предложено, чужая линия (человека ведёт другой — встречу ставим через него), конкурент адресата. Молчит больше 180 дней — не в топ;
   - **«оба ищут одних и тех же заказчиков» — ещё не связка.** Топ-3 — там, где связка самая конкретная: один заказчик, которого они закрывают вдвоём.
4. **Интро троих и точки пересечения** — из их расшифровок и переписки, с тайм-кодами.
5. **Подача:** титул с адресатом → его интро → по слайду на каждого из трёх (интро и точки пересечения) → «кто ещё под тебя» — сколько людей совпало по интро → «ставим встречи со всеми?». Скил `moy-dizayn` — для деки.
6. **Отправка** — только по поручению владельца. Контактов в подборке нет; имена третьих лиц — только тех, кто согласен на знакомство, остальные — нишей в 2 словах.
7. **Пополнить реестр** — интро и тиры остаются для следующих подборок; отметить в индексе, кому подборка сделана, чтобы не дублировать.

## Сценарии подборок
Сначала определи сценарий: от него зависит формат файла.

| Сценарий | Когда | Формат |
|---|---|---|
| Тройка | трое под одного человека, с созвонов | PDF |
| Десятка | топ-10 под одного человека | PDF |
| Больше десяти | вся база под человека | таблица; десятка входит в неё первыми строками |
| Круг | хотим свести 4–8 фаундеров с общим покупателем | одна общая дека PDF на всех — скил `krugi` |

Почему: PDF читается за минуту и пересылается, длинный список удобнее таблицей с фильтрами. Круг — не подборка одному человеку, а знакомство группы. Слова владельца сохраняй в `docs/decisions.md`. Было: топ-3 → топ-15 с интро → вся база. Стало: четыре сценария выше (старый порядок заменён 11.11.2026).

**Каждый PDF уходит в Telegram с превью первой страницы.** Без превью файл в чате — серая плашка с именем, и его неловко пересылать. Как: документ отправляй с `thumb` — JPEG первой страницы, до 320 px и до 200 КБ (на Mac: `sips -s format jpeg -Z 320 файл.pdf --out превью.jpg`). После отправки прочитай сообщение обратно и проверь, что превью есть. Если в проекте уже есть свой инструмент отправки с превью — отправляй через него.

## Круг
Запрос «сделай ему круг», «подборка на круг», «собери круги» — скил `krugi`: отбор, источники людей, пробные круги, общая дека, рабочая группа и лист партнёра. Почему: круг — знакомство группы, а не подборка одному человеку, и у него свой порядок работы. Было: правила круга жили в этом скиле. Стало: отдельный скил `krugi` (12.11.2026).

## Приёмка
- У адресата — все 5 пунктов, у каждого основание: созвон с тайм-кодом или переписка с датой.
- У каждого из троих — точка пересечения с адресатом, подтверждённая его словами.
- Исключения проверены фактом; конкурентов и уже сведённых нет.
- Контактов нет; пакет не уходит без «да» владельца.
- Дальше — по сценариям: десятка PDF, потом таблица с остальными (порядок «топ-15, вся база» заменён 11.11.2026).
