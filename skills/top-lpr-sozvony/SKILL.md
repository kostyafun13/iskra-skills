# Топ-ЛПР на созвоны

**Результат:** волна из 10–12 человек твоей базы, кому стоит написать прямо сейчас. По каждому: почему он, кто для него топ-ЛПР (должность и 3 компании) и готовое сообщение твоим тоном с твоим интро. Ты пересылаешь сам, по одному.

**Почему это работает:** человеку уходит не приглашение, а вопрос про ЕГО рост: «тебе ведь нужны вот такие ЛПР в таких компаниях — правильно понял?». Ответ «да, и ещё вот эти» — это его список целей и повод для созвона. Поэтому сердце скила — правильно названный топ-ЛПР, а не длина списка.

## Нужно до начала
- Твоя база в одном месте — скил `indeks-bazy` (личка Telegram, созвоны, таблицы). Без него ИИ смотрит только переписку.
- Telegram для чтения переписок — скил `podklyuchit-telegram`. Отправлять людям ИИ не будет.
- Твоё интро — картинка или текст по 5 пунктам. Нет интро — скил `strateg` поможет его собрать.

## Первый запуск — бриф
Если в `PROFILE.md` нет раздела «Топ-ЛПР на созвоны», задай вопросы по одному. У каждого есть вариант «по умолчанию». Ответы сохрани в `PROFILE.md` и больше не спрашивай.
1. Кого ищем? (по умолчанию — фаундеры ИТ-продуктов с выручкой от 30 млн ₽ в год, продукт маржинальный и тиражируемый, продают крупным клиентам)
2. Сколько человек в волне? (по умолчанию — 12)
3. Кого считаем тёплым? (по умолчанию — с кем была встреча, созвон или переписка, где отвечал он сам)
4. Где твоё интро: путь к картинке или текст? (по умолчанию — без вложения, только текст)
5. Куда складывать тексты? (по умолчанию — в «Избранное» Telegram и папкой на диске)

## Порядок
1. **Запрос дословно** — записать, кого ты просишь и по каким критериям. Не назвал критерии — бери ответ брифа.
2. **Исключить, кому уже писали.** Реестр волн `VOLNY.md` в рабочей папке (кто, когда, каким текстом). Плюс отказы («не интересно»), чёрный список индекса, люди, которых ведёт кто-то другой, и те, кто просил паузу до даты.
3. **Пул — только твоя база и только тёплые.** Индекс базы, личка, календарь созвонов, твои таблицы. Чужие списки, каталоги и анкеты — не «твоя база»: написать по ним можно, но это уже холодный заход, а не этот скил. Массово искать людей поиском Telegram нельзя: сотни запросов подряд — и Telegram на многие часы закроет поиск и чтение профилей.
4. **Отбор и порядок.** Сначала те, к чьим топ-ЛПР у тебя есть живой выход: знакомый в нужной компании, с которым была встреча или переписка. Потом по выручке: открытая отчётность → его слова → анкета. Цифру без источника в список не ставим. Потом тёплые с видимым масштабом без цифры. Два прямых конкурента — один в волну. Услуги, агентства и железо — ниже чистого ИТ-продукта.
5. **Топ-ЛПР на каждого:**
   - сегмент, где одна подпись даёт сделку на миллионы;
   - должность: «директор по e-com», «финансовый директор», «руководитель контакт-центра», а не «гендиректор вообще»;
   - 3 компании. Те, кто уже его клиенты, вычёркиваем;
   - если человек сам называл, кто ему нужен, берём его слова.
6. **Текст.** Шаблон, слово в слово, только вставки:
   ```
   <Имя>, привет!
   А кто тебе нужен для масштабирования <проект>: <ЛПР>: <3 компании> — правильно понял?

   Прикрепляю своё интро
   ```
   Пример вставки: «А кто тебе нужен для масштабирования: финансовые директора платформ, где тысячи курьеров: Самокат, Купер, Яндекс Еда — правильно понял?»
   - Есть живой выход — строка перед интро: «Кстати, в <компания> у меня есть знакомый <роль>.» Только если с ним была встреча или переписка. Строка из каталога или справочника — не знакомство. Имя знакомого не пишем, только роль.
   - Обращение — как ты зовёшь человека в переписке. Тон, приветствие и запретные слова — по скилу `moy-ton`. Числа — цифрами.
   - Интро прикладывается к сообщению: текст — подпись к картинке.
7. **Доставка.** Сначала одно сообщение со списком волны: номер, имя, ник, проект, пометки («писали раньше», «лучше завтра с 10:00» для тех, с кем переписки не было). Дальше по каждому два сообщения: «N. Имя @ник — проект» с одной строкой фактов, потом его текст с интро. Плюс папка на диске: файл на человека и файл со списком. В конце — строка волны в `VOLNY.md`.

## Чего скил не делает
- Не пишет людям: пересылаешь ты сам.
- Не берёт людей из чужих баз и не выдаёт строку справочника за знакомство.
- Не называет цену и проценты: это разговор на созвоне.

## Приёмка
- В волне ровно столько человек, сколько просил. Никого из `VOLNY.md`, отказавшихся, из чёрного списка и чужих линий.
- Все из твоей базы и тёплые по ответу брифа — у каждого видно, где была встреча или переписка.
- У каждого: выручка с источником или «не называл», топ-ЛПР должностью и 3 компании.
- Строка «у меня есть знакомый» — только при живом контакте.
- Порядок в «Избранном» после серии цел: список → человек → текст. Чужое сообщение вклинилось — сказать одной строкой, не удалять.
- Если ИИ сам кладёт сообщения в «Избранное» — не больше 25 в час с аккаунта: волна из 12 — это 25 сообщений, двенадцать с лишним — в два захода.
