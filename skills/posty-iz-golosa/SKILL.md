# Посты из голосового

**Результат:** пост в канале или в отложке, в тоне владельца, с обложкой в его дизайне.

## Порядок
1. **Забери голосовые** оттуда, куда указал владелец (Избранное Telegram, папка). Расшифруй. Готовую расшифровку повторно не заказывай.
2. **Одна запись — один пост**, если владелец не сказал иначе. Мысль автора сохраняй, слова чисти от оговорок.
3. **Пиши в тоне** из `PROFILE.md`: главная мысль первой строкой, короткие абзацы, числа цифрами, без канцелярита.
4. **Прогони экспресс-линзами** (скил `linzy`, режим 3×3): 3 линзы, по 3 вопроса. Внеси только правки, которые прошли.
5. **Обложка** — скил `moy-dizayn`.
6. **Отложка:** ставь посты с перерывом примерно в сутки, каждый следующим в очередь канала. Время отложки проверь чтением очереди обратно.
7. **Сторис** к посту — скил `storis` после выхода поста.

## Приёмка
- Пост прочитан обратно из канала или очереди отложек: текст, обложка, время.
- В посте нет слов из списка «не пишу никогда» в профиле.
- Владельцу — одна строка: сколько постов, на какие даты.

## Постоянный чат постов
Держи отдельный чат «Посты». Пересоздавай его по расписанию скилом `peresozdat-chat`, чтобы контекст оставался чистым.
