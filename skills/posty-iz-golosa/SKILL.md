# Посты из голосового

**Результат:** пост в канале или в отложке, в тоне владельца, с обложкой в его дизайне.

## Первый запуск — бриф
Если в `PROFILE.md` нет раздела «Посты из голосового», до работы задай вопросы по одному. У каждого есть вариант по умолчанию — человек может ответить «по умолчанию». Ответы сохрани в `PROFILE.md` в раздел «Посты из голосового» и больше не спрашивай.
1. Какой канал ведёшь? Пришли ссылку. (по умолчанию — спрошу при первом посте)
2. Пришли 3 своих поста, которыми доволен, или канал, чей стиль нравится. (по умолчанию — пишу коротко и по делу)
3. Куда будешь кидать голосовые? (по умолчанию — Избранное Telegram)
4. Как часто выпускать посты? (по умолчанию — раз в сутки)
5. Какие слова ты не пишешь никогда? (по умолчанию — канцелярит и штампы)

## Порядок
1. **Забери голосовые** оттуда, куда указал владелец (Избранное Telegram, папка). Расшифруй. Готовую расшифровку повторно не заказывай.
2. **Одна запись — один пост**, если владелец не сказал иначе. Мысль автора сохраняй, слова чисти от оговорок.
3. **Пиши в тоне** из `PROFILE.md`: главная мысль первой строкой, короткие абзацы, числа цифрами, без канцелярита.
4. **Прогони экспресс-линзами** (скил `linzy`, режим 3×3): 3 линзы, по 3 вопроса. Внеси только правки, которые прошли.
5. **Обложка** — скил `moy-dizayn`.
6. **Отложка:** ставь посты с перерывом примерно в сутки, каждый следующим в очередь канала. Время отложки проверь чтением очереди обратно.
7. **Сторис** к посту — скил `storis` после выхода поста.

## Приёмка
- Пост прочитан обратно из канала или очереди отложек: текст, обложка, время.
- В посте нет слов из списка «не пишу никогда» в профиле.
- Владельцу — одна строка: сколько постов, на какие даты.

## Постоянный чат постов
Держи отдельный чат «Посты». Пересоздавай его по расписанию скилом `peresozdat-chat`, чтобы контекст оставался чистым.

## Самообучение
Поправка к результату («не так, надо вот так») — переделай результат и допиши правило в этот SKILL.md: что делать, почему, было → стало. Режим — из `PROFILE.md`, раздел «Режим обновления скилов»: «сам» — обнови и скажи одной строкой; «спрашивать» — предложи правку и обнови после «да»; «после серии» — копи правки и предложи пакетом. Режима в профиле нет — спроси один раз. Перед свёрткой проверь, что все правки чата легли в скилы.
