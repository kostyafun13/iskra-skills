# Поставить VPN-стража

**Результат:** значок 🛡 в строке меню Мака. Случайно открыл Клод без VPN или VPN отвалился во время работы — экран перекрывает окна и не даёт работать, пока VPN не включишь.

## Как ведёт себя
Реагирует только на одно: **приложение из настройки открыто И нужный VPN выключен.**

1. Плохой замер держится около 4 секунд → экран на всех мониторах. Короткий реконнект VPN экран не вызывает.
2. На экране отсчёт: через 10 секунд приложение закрывается само. Не закрылось по-хорошему за 5 секунд → закрывается силой, незавершённая работа в нём прервётся.
3. VPN вернулся до конца отсчёта → экран исчезает, приложение остаётся открытым.

Строка меню и Док видны всегда: VPN включается прямо при показанном экране. Пока экран показан, страж — активное приложение, поэтому в строке меню видны все значки, а клавиатура не попадает в приложения под экраном. Экран ушёл — фокус возвращается назад.

| Значок | Что значит |
|---|---|
| 🛡 | VPN включён |
| 🟡 | VPN выключен, но приложение закрыто, или баннер закрыт вручную |
| ⛔ | показан экран |
| 💤 | страж выключен |

Меню значка:
- **Закрыть баннер** — экран убран, отсчёт отменён. Страж молчит, пока VPN не вернётся или приложение не закроют.
- **Выключить стража до перезагрузки** — молчит, пока не нажмёшь «Включить стража» или не перезагрузишь Мак.
- **Показать баннер (12 сек)** — посмотреть, как выглядит. Ничего не закрывает.
- **Открыть лог.**

На небольшом экране macOS прячет значки, когда меню активного приложения длинное: например, в Chrome значка стража может не быть. Перейди в Клод или перетащи значок правее с зажатым ⌘, место запомнится.

## Чего не делает
- Не ходит в сеть и не проверяет страну: смотрит только на процессы и интерфейсы Мака. Если VPN включён, но трафик идёт мимо него, страж этого не увидит.
- Не стережёт браузер: claude.ai в браузере он не видит.
- Не закрывает Claude Code и Codex, запущенные в терминале. Закрывает только приложения из настройки.
- Не снимает риск: Клод и Кодекс официально не работают в России, аккаунт могут заблокировать и при включённом VPN.

## Сколько стоит
Бесплатно. Около 30 МБ памяти, нагрузка почти нулевая.

## Первый запуск — бриф
Если в `PROFILE.md` нет раздела «VPN-страж», до работы задай вопросы по одному. У каждого есть ответ по умолчанию — человек может просто согласиться.
1. Какие приложения стеречь? (по умолчанию — Claude и Codex, те, что установлены)
2. Какой VPN считать включённым: только конкретный или любой? (по умолчанию — любой)
3. Закрывать приложение через 10 секунд или только показывать экран? (по умолчанию — закрывать через 10 секунд. Минус: если человек отошёл, а VPN отвалился, работа в приложении прервётся.)

Ответы запиши в `PROFILE.md`, раздел «VPN-страж».

## Порядок для ИИ
`SKILL_DIR` — папка этого скила: `~/.claude/skills/postav-vpn-strazha` или `~/.codex/skills/postav-vpn-strazha`.

**0. Проверь Мак.** `xcode-select -p` — путь есть. Нет → `xcode-select --install`, владелец жмёт «Установить» и ждёт.

**1. Проверь, что уже стоит.** `ls ~/Library/LaunchAgents | grep -i -E 'vpn|strazh|guard'`. Нашёлся другой сторож VPN → покажи владельцу и спроси, что с ним делать. Два сторожа рядом дадут два экрана.

**2. Узнай VPN — если в брифе конкретный.** При ВКЛЮЧЁННОМ VPN: `ps -axco comm | sort -u | grep -i -E 'vpn|wg|wireguard|amnezia|xray|sing|tun'`. Имя движка VPN, а не окна программы: для AmneziaWG это `amneziawg-go`. Сомневаешься, какой процесс нужен → спроси владельца, не угадывай.

**3. Настрой.** Создай папку `~/Library/Application Support/vpn-strazh/` и файл `nastroyka.txt` по образцу `$SKILL_DIR/vpn-strazh/nastroyka.primer.txt`:
- `prilozhenie=<bundle id>|<имя>` — по строке на приложение. Bundle id бери с самого приложения: `/usr/libexec/PlistBuddy -c 'Print :CFBundleIdentifier' /Applications/<Имя>.app/Contents/Info.plist`. Приложения нет на Маке → не пиши.
- `vpn=<процесс>|<имя>` или `vpn=любой`.
- `zakryt_cherez=10` или `0`, если только экран.

**4. Проверь, не включая.** Собери и спроси состояние, ничего не запуская надолго:
```bash
clang -fobjc-arc -O2 -framework Cocoa -o /tmp/vpn-strazh "$SKILL_DIR/vpn-strazh/vpn_strazh.m" && /tmp/vpn-strazh --status; rm -f /tmp/vpn-strazh
```
Нужно `vpn=on overlay=hidden`. Если `vpn=off` при включённом VPN — настройка неверная, вернись к шагу 2. **Не ставь стража, пока здесь не `vpn=on`:** он закроет приложение, из которого ты работаешь, и эта сессия оборвётся.

**5. Поставь.** `bash "$SKILL_DIR/vpn-strazh/ustanovit.sh"`. Автозапуск при входе и перезапуск при сбое включатся сами. macOS покажет «Добавлены фоновые объекты» — это нормально.

## Как проверять при правках
Настоящее приложение из своей сессии не закрывай: сессия оборвётся. Проверяй на Калькуляторе в отдельной папке:
```bash
mkdir -p /tmp/strazh-test && printf 'prilozhenie=com.apple.calculator|Калькулятор\nvpn=net-takogo|Тест\nzakryt_cherez=3\n' > /tmp/strazh-test/nastroyka.txt
open -g -j -a Calculator && "$HOME/Library/Application Support/vpn-strazh/vpn-strazh" --dir /tmp/strazh-test --tiho --sek 12
```
С `--dir` приложения `com.anthropic.*` игнорируются, `--tiho` не показывает окон. В логе должно быть: экран → закрываю → убираю экран. `--kartinka файл.png` рисует экран в файл.

## Приёмка — вместе с владельцем, 2 минуты
Предупреди: связь с ИИ на эту минуту оборвётся, и ответов не будет, пока VPN выключен. Клод не отвечает без VPN, поэтому шаги скажи заранее.
1. Значок 🛡 в строке меню. Меню → «Показать баннер (12 сек)» → экран на всех мониторах, строка меню видна.
2. Приложение открыто, выключи VPN → через 4 секунды экран с отсчётом.
3. Сразу включи VPN из строки меню → экран исчез, приложение осталось открытым.
4. Снова выключи VPN → меню значка → «Закрыть баннер» → экран исчез, отсчёта нет. Включи VPN обратно.
5. Меню → «Выключить стража до перезагрузки» → значок 💤. Меню → «Включить стража» → значок 🛡.

Проверка по логу: `tail ~/Library/Logs/vpn-strazh.log`.

## Если что-то не так
- **Красный экран при включённом VPN** → меню значка → «Выключить стража до перезагрузки», это снимет экран сразу. Потом шаг 2: скорее всего, в настройке не то имя процесса. Обновился VPN или его протокол — имя движка могло поменяться.
- **Экран не появляется** → `--status` из README: приложение не в `apps=` → неверный bundle id. `strazh=off` → страж выключен в меню.
- **После правки настройки ничего не поменялось** → настройка читается при старте: `launchctl kickstart -k gui/$(id -u)/ru.iskra.vpn-strazh`.
- **Убрать совсем:** `bash "$SKILL_DIR/vpn-strazh/ustanovit.sh" --udalit`.
