# Подбор скила

**Зачем:** агент не всегда сам понимает, какой скил звать. Этот скил делает выбор явным.

## Порядок
1. **Пойми результат,** который хочет владелец: пост, встреча, подборка, правка, разбор.
2. **Пройди список установленных скилов** по их `description`. Выбери один самый подходящий; если задача из двух частей — назови 2 по порядку.
3. **Скажи одной строкой:** «Работаю по скилу X» или «Работаю без скила — подходящего нет».
4. **Выполни** по выбранному скилу.
5. **Ошибся** (владелец поправил) — исправь `description` скила: добавь фразу владельца в триггеры, чтобы в следующий раз выбор был верным.
6. **Задача повторяется, а скила нет** — предложи оформить её скилом (скил `kanon`).

## Каталог — 8 разделов, по порядку включения
По просьбе «какие у тебя скилы» — нумерованный список по разделам: номер · имя · одна строка, когда звать. Включаются по разделам, а не всё сразу: каждый следующий опирается на предыдущий. Стратег и индекс без раздела 1 не запускаются.

0. **С чего начать** — `podbor-skila`.
1. **Источники информации** — `podklyuchit-telegram`, `podklyuchit-zoom`, `podklyuchit-google`, `podklyuchit-rasshifrovku`, `postav-diktovku`.
2. **Упаковка интро** — `upakovka-intro`: за 15–30 минут интро по 5 пунктам и карточка в дизайне владельца; первый шаг перед Стратегом.
   **Стратег** — `strateg`: зона гениальности, цели, сегменты, офферы, критерии, кейсы — по созвонам владельца. Старое имя — `lb-sp`, ЛБ СП.
3. **Индекс своей базы** — `indeks-bazy`: единая база данных владельца.
4. **Подборки** — для партнёров: обмен выходами на топ-ЛПР и назначение встреч, от узкого к широкому: `podborka-top3` → `top15-intro` → вся база из `indeks-bazy`.

## Приёмка
В каждом ответе на задачу есть строка «работаю по скилу …» или «работаю без скила».

## Самообучение
Поправка к результату («не так, надо вот так») — переделай результат и допиши правило в этот SKILL.md: что делать, почему, было → стало. Режим — из `PROFILE.md`, раздел «Режим обновления скилов»: «сам» — обнови и скажи одной строкой; «спрашивать» — предложи правку и обнови после «да»; «после серии» — копи правки и предложи пакетом. Режима в профиле нет — спроси один раз. Перед свёрткой проверь, что все правки чата легли в скилы.
