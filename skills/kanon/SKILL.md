# Канон

**Результат:** правило записано в одно правильное место и сработает в следующий раз без напоминания.

## Куда класть
- **Действует всегда** (язык, формат, запреты, деньги) → системный файл (`CLAUDE.md` / `AGENTS.md`).
- **Включается на конкретной задаче** → `SKILL.md` этого скила; нет скила — создай новый.
- **Нельзя забыть** → проверка в инструменте (скрипт, хук) + строка-ссылка в системный файл.
- **Это факт о человеке или проекте**, а не правило работы → файл состояния проекта.

## Порядок
1. Сохрани слова владельца дословно с датой в `docs/decisions.md`.
2. Запиши правило: что делать · **почему** (без причины правило не переносится на другой случай) · было → стало.
3. Одно правило — в одном месте. В остальных — строка-ссылка.
4. Не сжимай старые правила при дописывании: дописывай новое, старое помечай «заменено, дата».
5. Исправь текущий результат по новому правилу.
6. Одной строкой скажи владельцу, куда записал.

## Приёмка
Правило прочитано обратно из файла; на исходном случае скил выбирается и действует по новому правилу.
