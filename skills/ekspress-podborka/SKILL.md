# Экспресс-подборка под проект для звонка

**Результат:** перед звонком у тебя один файл на экран-два. Кто эта компания, кому она продаёт, и **кого из твоей базы ты можешь ей дать уже сейчас** — с фактом, почему этот человек открывает дверь. С этим заходишь на звонок не с пустыми руками, а со встречным предложением.

**Почему это работает:** на первом звонке выигрывает тот, кто первым назвал 3 конкретных выхода. Имя и компанию можно завтра проверить, а «поищу у себя» проверить нельзя.

## Нужно до начала
- Твоя база в одном месте — скил `indeks-bazy`. Без него ИИ видит только переписку.
- Telegram для чтения переписок — скил `podklyuchit-telegram`. Людям ИИ ничего не отправляет.

## Первый запуск — бриф
Если в `PROFILE.md` нет раздела «Экспресс-подборка», задай вопросы по одному. У каждого вопроса есть ответ «по умолчанию». Ответы сохрани туда же и больше не спрашивай.
1. Кого считаем тёплым? (по умолчанию — человек сам ответил тебе за последние 30 дней)
2. Сколько тёплых выходов показывать? (по умолчанию — до 7)
3. Кто из твоих партнёров или участников группы уже охотится за похожими клиентами — с кем не конкурировать? (по умолчанию — спрошу, когда увижу пересечение)
4. Куда класть файл подборки? (по умолчанию — `podborki/<компания>_<дата>.md` в рабочей папке)

## Порядок
0. **Что уже есть** — переписка с компанией и тем, кто её привёл, прошлые подборки, индекс базы. Ничего не качаем заново.
1. **Кто они — фактами из их материалов.** Источники по порядку: дека → сайт → канал. Продукты — по строке на каждый. Клиенты — только названные по имени. Кейсы — цифрами «было → стало». Контакт и его роль. Кто их привёл. Выручка — если названа; не названа — так и пиши, не угадывай.
2. **Кто им нужен — их словами.** Лучше всего слова фаундера или того, кто их привёл. Нет таких слов — твоя гипотеза с пометкой «гипотеза» и короткий вопрос, который можно отправить связному: «не знаешь, кто у них сейчас в фокусе?». Гипотеза часто мимо: важным оказывается не сектор клиента, а другой признак, например объём контента.
3. **Куда продают — 5–7 направлений.** У каждого: кто уже клиент (из их материалов) → 3–6 целевых компаний по имени с пометкой «гипотеза, сверить на звонке» → ЛПР по должностям. Последним направлением, если подходит, — держатели пулов: агентства, платформы, клубы, через которых выходишь сразу на много клиентов.
4. **Кто есть в твоей базе.** По каждому направлению — отдельный поиск по индексу, и отдельный — по названиям целевых компаний. Берёшь только тех, с кем есть переписка.
   - **Теплота — по ЕГО последнему ответу**, а не по твоему сообщению. Тёплый — ответил за срок из брифа. Остыл — пишешь дату его последнего ответа.
   - **Выход — фактом:** что именно человек открывает, его словами, с датой. «Работает в маркетинге» — не выход. «Сам назвал партнёрские каналы: два банка и маркетплейс» — выход.
   - Раскладка: 🔥 **тёплые** (имя, компания — направление, факт с датой, чего ещё не спрашивал, дата его ответа) → **слабее или остыли** строкой с причиной → **пусто** — список целевых компаний, на которые выходов нет.
   - Соседний продукт или возможный конкурент за тот же бюджет — помечай «риск», решать тебе.
   - **Калибр выхода = калибр клиента.** Компания продаёт крупным брендам — в выходы берёшь только тех, кто сам работает с крупными клиентами: корпорации, платформы, банки, сетевые агентства. Не выходы: те, кто работает с малым бизнесом, тот, кто сам ещё не окреп, тот, у кого компания и так есть, конкурент. Совпадение по сектору без совпадения по размеру даёт пустые интро.
   - **Продаёт крупным — сканируй всю базу на признаки крупного бизнеса** (названия крупных компаний, «корпорации», «директор по маркетингу», «рекламный бюджет»), а не только поиск по направлениям: поиск по направлениям тащит мелких.
   - **Первыми — участники твоей группы и свежие созвоны.** База отстаёт от разговоров: клиенты, которых человек назвал на созвоне неделю назад, в карточках ещё нет. До поиска по базе посмотри участников своей группы и итоги созвонов за 2 недели, а в выжимке спроси владельца: «кого ещё вспомнишь под этих клиентов?».
   - **Сегменты бери со всех материалов компании** — сайт, деки, канал. Там, где у тебя сильнее база, может оказаться сегмент, которого нет в деке.
5. **Стык с твоими.** Проверь, не охотится ли кто-то из твоих партнёров или участников группы за тем же покупателем. Если да — отдельный блок:
   - где пересекаетесь: тот же ЛПР, те же люди в подборках — поимённо, сколько из скольких;
   - где разные: другая строка бюджета, другой продукт;
   - как дополняете: общий пакет, клиенты одного — цели другого;
   - правило: клиента ведёт тот, кто привёл первым, второй заходит дополнением; людей из чужой подборки не отдаёшь, пока её владелец не выбрал своих.
6. **Что спросить на звонке — 3–5 вопросов:** выручка, сколько платящих клиентов, средний чек и срок от пилота до денег · кто из их клиентов готов дать интро встречно · вопросы по стыку · есть ли партнёрская ставка за приведённого клиента. Цену своего продукта на первом звонке не называешь: сначала ценность и «на сколько из 10?».
7. **Что не закрыто** — что ещё нужно для решения: выручка, что дают взамен, договорённость со смежником, у кого из выходов ещё не спросил про интро.

В чат — выжимка на экран телефона: кто они одной строкой, кто им нужен, тёплые выходы по строке, стык, ссылка на файл.

## Приёмка
- У каждого тёплого: факт его словами с датой и теплота по его последнему ответу; сказано, чего ещё не спрашивал.
- Клиенты компании — только названные в её материалах. Целевые компании помечены «гипотеза».
- «Кто им нужен» — их словами с источником или явная пометка «гипотеза» и вопрос связному.
- Блок «пусто» перечисляет компании, а не «по остальным пусто».
- Стык проверен и записан, даже если пересечений нет.
- Контактов людей в файле наружу нет; людям ничего не ушло без твоего «да».

## Самообучение
Поправка к подборке — переделай файл и допиши правило в этот SKILL.md: что делать, почему, было → стало. Режим — из `PROFILE.md`, раздел «Режим обновления скилов».
