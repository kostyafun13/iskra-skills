# Интро-карточка человека

Сценарий внутри «Моего дизайна» для запросов «сделай карточку интро», «задизайни интро», «карточка человека». Текст интро берётся из `materials/intro_5.md` (скил `upakovka-intro`); текст без визуальной карточки этого сценария не требует.

## Порядок форматов
1. Сначала собери и покажи **вертикальную** карточку, пропорция 4:5.
2. Затем спроси: «Нужна горизонтальная версия?» Оба формата автоматически не делай. Правки вертикали вноси до адаптации.
3. Горизонталь — перестрой композицию, а не растягивай вертикаль.

## Композиция
- Фон и цвета — из брендбука владельца (`PROFILE.md`, «Дизайн»): базовый светлый фон, графит для текста, один акцентный цвет для номеров и выносок.
- Сверху заголовок «<Имя> — <короткий оффер с числом и сроком>» и подзаголовок.
- Человек — в центре; вокруг пять пронумерованных блоков акцентными номерами 01–05 и тонкими выносками: **Оффер · Для кого · Кейсы · Кто нужен · Что даю взамен**. Пятый блок — широкой полосой внизу.
- Под фото — имя, роль, проверенный масштаб одной строкой.
- Самая нижняя тёмная полоса «Ключевая идея» — одна-две строки.
- Фото: по возможности в полный рост или по плечи на нейтральном фоне; портрет берётся из `materials/foto_intro.png` (его делает скил `upakovka-intro`: Codex — встроенной генерацией, Claude — через ключ ProxyAPI); без фото — знак или инициалы, пустоту не оставляй.
- Шрифты: заголовки — плотный гротеск, основной текст — засечный, ключевые числа и названия — жирным.

## Правила
- Тексты — только из подтверждённого `intro_5.md`; новые факты на карточке не появляются.
- Одна главная мысль в каждом блоке; длинный текст не прячь мелким шрифтом — сократи.
- Число результата и подпись стоят рядом; потенциал не выглядит как полученная выручка.
- Не больше одного акцентного цвета на карточке.

## Приёмка
Открой PNG и посмотри глазами: пять блоков на месте, портрет не обрезан, текст не вылезает, на телефоне читается без увеличения; линзы Айва и Парротта пройдены, правки названы одной строкой.
