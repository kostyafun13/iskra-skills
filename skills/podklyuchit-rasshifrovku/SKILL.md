# Подключить расшифровку голоса

**Зачем:** голосовые и созвоны — главный источник ваших слов. ИИ сам слушать не умеет: ему нужен сервис распознавания. Подключается один раз, дальше ИИ расшифровывает сам.

## Какой сервис выбрать
- **★ Яндекс SpeechKit — по умолчанию.** Оплата российской картой, хорошо понимает русскую речь. Цена — порядка 1 ₽ за минуту речи, точную смотрите в тарифах консоли.
- **OpenAI — если есть зарубежная карта.** Ключ на platform.openai.com. Цена — порядка $0,003–0,006 за минуту, смотрите страницу цен OpenAI.
- **Whisper на своём компьютере — не советуем.** Бесплатно, но на ноутбуке медленно и сильно греет. Скрипт его не поддерживает.

Подписка ChatGPT или Claude ключа для расшифровки не даёт — это отдельный счёт в сервисе.

## Яндекс SpeechKit — что делает владелец, один раз, около 15 минут
1. Войти в console.yandex.cloud своим Яндекс ID.
2. Создать платёжный аккаунт: физлицо, российская карта. **Грант:** на 20.10.2026 официальная документация пишет, что стартовый грант новым клиентам недоступен. Если консоль всё же предложит грант — карту привязывайте сразу при создании платёжного аккаунта, иначе грант не начислят.
3. В каталоге — «Сервисные аккаунты» → «Создать»: имя, например `stt`, роль `ai.speechkit-stt.user`.
4. Открыть этот аккаунт → «Создать новый ключ» → «API-ключ». Спросят область действия — выбрать распознавание речи SpeechKit. Ключ показывается один раз: сразу вписать его в `.env` (ИИ создаст файл и откроет). В чат не вставлять.

## OpenAI — запасной путь
platform.openai.com → API keys → создать ключ, пополнить баланс. В `.env`: `STT_PROVIDER=openai` и `OPENAI_API_KEY`.

## Что делает ИИ
1. Копирует `scripts/` в `connections/rasshifrovka/`, ставит `python3 -m pip install -r requirements.txt`, копирует `env.example` в `.env`.
2. Проверяет ffmpeg — без него нельзя порезать запись. Нет — ставит: Mac `brew install ffmpeg`, Windows `winget install ffmpeg`.
3. Ведёт владельца по шагам выбранного сервиса.
4. Проверяет: `python3 rasshifrovka_app.py status` → «Расшифровка работает».
5. Расшифровывает: один файл — `file --in запись.m4a`; папку — `folder --in private/files`. Текст ложится рядом с файлом в `.txt`. Готовый `.txt` есть — файл пропускается, второй раз не оплачивается.
6. Голосовые из Telegram: скил `podklyuchit-telegram`, команда `download` в папку, затем `folder` по этой папке.

## Созвон из Zoom — точно и дёшево
**Зачем:** Zoom бесплатно знает, кто говорил, но путает имена, компании и цифры. Сервис распознавания пишет их точно, но не знает, кто говорит, и берёт деньги за каждую минуту. Вместе: кто говорил — из Zoom, а в сервис уходят только короткие куски с конкретикой. Час созвона обходится в минуты, а не в час.
1. Скил `podklyuchit-zoom`: `list`, затем `transcript` (расшифровка Zoom, бесплатно) и `audio` (звук того же созвона).
2. **Прочитай .vtt сам** и выбери номера реплик, где есть конкретика: имена людей, компании, цифры и суммы, сроки, условия, договорённости — и места, где Zoom явно написал чепуху. Приветствия и «понял, согласен» не бери. Номера — это числа над строками времени в .vtt.
3. Посчитай без трат: `sozvon --vtt созвон.vtt --audio созвон.m4a --out стенограмма.md --kuski "12, 15-18" --plan`. Скажи владельцу, сколько минут уйдёт в сервис.
4. Тот же запуск без `--plan`. В стенограмме строки с ✓ сверены по звуку. Рядом `.sverka.json`: текст Zoom и текст по звуку — сравни и поставь в итоговый текст правильные имена, названия и цифры.
5. Номера не выбрал — скрипт сам возьмёт реплики с цифрами, латиницей, суммами и деловыми словами. Имён он не видит: Zoom пишет их строчными и с ошибками. Поэтому имена людей и компаний выбирай сам — это главное, ради чего режим.
6. `--vse` — сверить весь разговор. Только когда нужны дословные формулировки целиком: это цена всего созвона.

Весь звук остаётся на компьютере, в сервис уходят только выбранные куски. Больше 15 минут скрипт не отправит без `--limit-min` — поднимать только после «да» владельца.

## Что важно
- Принимает голосовые Telegram, mp3, m4a, wav, видео mp4 и mov — звук достаётся сам.
- Яндекс получает запись кусками по 25 секунд: так работает его быстрый режим. Текст приходит без знаков препинания — ИИ расставит их сам, если нужно.
- Чужие записи расшифровывать только с согласия людей на записи.

## Проверка — подключено, когда
- `status` печатает «Расшифровка работает»;
- тестовое голосовое длиннее 30 секунд расшифровано целиком, без обрыва в середине;
- стенограмма созвона: у каждой строки есть имя, строки с именами и цифрами отмечены ✓;
- `.gitignore` закрывает `.env` и `private/`.

## Самообучение
Поправка к результату («не так, надо вот так») — переделай результат и допиши правило в этот SKILL.md: что делать, почему, было → стало. Режим — из `PROFILE.md`, раздел «Режим обновления скилов»: «сам» — обнови и скажи одной строкой; «спрашивать» — предложи правку и обнови после «да»; «после серии» — копи правки и предложи пакетом. Режима в профиле нет — спроси один раз. Перед свёрткой проверь, что все правки чата легли в скилы.
