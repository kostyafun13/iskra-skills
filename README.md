# Искра — скилы Клода и Кодекса

Первый скил — подключение Telegram — человек устанавливает вручную по шагу 0. Затем этот файл читает ИИ (Claude Code или Codex) и ставит остальные скилы по выбору владельца.

## Что внутри
- `skills/` — 28 папок: 27 скилов по 8 разделам (ниже) и указатель «ЛБ СП → Стратег» для старых ссылок; 4 подключения (Telegram, Zoom, Google, расшифровка голоса), «Поставить Диктовку» — голос в текст и чтение вслух на Маке — и 21 рабочий, среди них «Стратег» — зона гениальности, цели и офферы по твоим созвонам, «Подборка топ-3» — для обмена выходами на топ-ЛПР, «Топ-ЛПР на созвоны» — десяток тёплых фаундеров из твоей базы, кому написать на созвон, «Разбор переписок» — чтобы ни одна переписка не зависала, «Индекс своей базы» — единая база твоих данных: скан базы, под продукт, под группу и чужие базы партнёров, плотное заполнение всех, с кем был созвон, и таблица соцактива без имён, и «Передай пингеру» — линия уходит на контроль, а чат закрывается без потерь. Каждый — папка с `SKILL.md` и `agents/openai.yaml` (русское имя и первая фраза в Codex). У скилов подключения ещё папка `scripts/`, у Диктовки — папка `diktovka/` с исходниками приложения.
- `PROFILE_TEMPLATE.md` — профиль владельца. Скилы берут из него имя, тон, продукты и каналы.
- `CANON.md` — 8 правил для системного файла (`CLAUDE.md` или `AGENTS.md`).

## Порядок включения — 8 разделов
Включай по разделам, а не всё сразу: каждый следующий опирается на предыдущий.
0. **С чего начать** — подбор скила.
1. **Источники информации** — подключить Telegram, Zoom, Google, расшифровку голоса, поставить Диктовку. Без них стратег и индекс не запускаются.
2. **Упаковка интро → Стратег.** Сначала «Упаковка интро» — за 15–30 минут интро по 5 пунктам и карточка в твоём дизайне. Затем **Стратег** (было ЛБ СП — личный бренд для стратегических партнёрств) — зона гениальности, цели, сегменты, офферы, критерии и кейсы по твоим созвонам, без лишних вопросов.
3. **Индекс своей базы** — единая база твоих данных: скан, под продукт, под группу, чужие базы. Всех, с кем был созвон, заполняет плотно их словами и отдаёт таблицу соцактива без имён — с проверкой на утечки.
4. **Подборки** — для партнёров: обмен выходами на топ-ЛПР и назначение встреч. Топ-3 → топ-15 с интро → вся база. Плюс «Топ-ЛПР на созвоны» — десяток тёплых фаундеров из твоей базы, кому написать на созвон, с топ-ЛПР под каждого.
5. **Организация и коммуникации** — чаты с партнёрами, аутрич, дожим, разбор переписок, пингер, передай пингеру.
6. **Вывод информации** — посты из голосового, мой тон, мой дизайн, линзы, монтаж, сторис.
7. **Техничка** — канон, свёртка, пересоздать чат.

## Шаг 0 — подключи Telegram
Открой [скил на GitHub](https://github.com/kostyafun13/iskra-skills/tree/main/skills/podklyuchit-telegram), скачай репозиторий кнопкой Code → Download ZIP и распакуй. Папку `skills/podklyuchit-telegram` вручную положи в `~/.claude/skills/` для Claude Code или `~/.codex/skills/` для Codex. Открой новый чат и скажи: «Подключи мой Telegram». Создай приложение Telegram, внеси ключи в локальный `.env` и войди по коду в обычном терминале по подсказкам скила. Ключи и код в чат с ИИ не отправляй.

После подключения передай агенту ссылку на канал инструкций Искры. Агент прочитает его и поставит выбранные остальные скилы по ссылкам на GitHub из постов, включая Zoom, Google и расшифровку голоса. Их установка уже не требует ручного копирования каждого скила. Для расшифровок Zoom нужен платный тариф от Pro.

Telegram становится каналом работы агента: читать чаты, доставать фактуру, вести переписку о встречах, отправлять сообщения и интро по поручению, ставить разовые напоминания и проверять реакции. Отправки и встречи — по решению владельца. Подключение само по себе не даёт разрешения писать людям.

## Поставить один скил по ссылке
Ссылка на скил: `https://github.com/kostyafun13/iskra-skills/tree/main/skills/<имя>`.
Telegram устанавливается вручную по шагу 0. Порядок ниже — для остальных скилов после первого подключения.
- **Codex:** скажите «Поставь скил по ссылке <ссылка>». Встроенный установщик Codex сам скачает папку в `~/.codex/skills/` (личные скилы Codex также читает из `~/.agents/skills/`).
- **Claude Code:** скажите «Скачай папку скила по ссылке <ссылка> в `~/.claude/skills/<имя>`».
После установки скил доступен со следующего сообщения.

**Ошибка `CERTIFICATE_VERIFY_FAILED` на Mac** — Python с python.org не видит сертификаты. Выполни `python3 -m pip install certifi` и запусти установку с `SSL_CERT_FILE=$(python3 -m certifi)` перед командой.

## Первый запуск каждого скила
Скил сам задаст 3–7 вопросов по одному — у каждого есть ответ «по умолчанию». Ответы ложатся в `PROFILE.md`, повторно не спрашивает. Для тона, дизайна, постов и монтажа он попросит референсы: ваши тексты, каналы, презентации, ролики, которые нравятся. Дальше скил учится на ваших поправках сам (режим — в профиле).

## Поставить весь пак (порядок для ИИ)
0. Источник — репозиторий https://github.com/kostyafun13/iskra-skills: скачай его (`git clone` или Code → Download ZIP) и используй папку `skills/`. Файлов скилов в каналах Искры нет — только ссылки на этот репозиторий.
1. **Спроси владельца, где он работает:** Claude Code, Codex или оба.
2. **Положи скилы** — по разделам, в порядке 0 → 7:
   - Claude Code — в `~/.claude/skills/<имя>/SKILL.md` (для всех проектов) или `<проект>/.claude/skills/`.
   - Codex — в `~/.codex/skills/<имя>/SKILL.md` или `<проект>/.agents/skills/`.
   - Работает в обоих — положи в оба места одинаковые копии.
3. **Заполни профиль.** Скопируй `PROFILE_TEMPLATE.md` в корень рабочей папки как `PROFILE.md`. Задавай владельцу вопросы по одному, голосом или текстом. Чего он не знает — оставь пустым, не выдумывай.
4. **Допиши канон.** Добавь блок из `CANON.md` в конец системного файла: `CLAUDE.md` для Claude, `AGENTS.md` для Codex.
5. **Заведи 2 лога** в рабочей папке: `docs/decisions.md` (решения владельца дословно, с датой) и `docs/worklog.md` (что сделано и чем проверено).
6. **Проверь установку:** спроси сам себя «какие у меня скилы?» — должно найтись 27 скилов и указатель `lb-sp`. Затем выполни скил `podbor-skila` на фразе «сделай пост из голосового» — он должен выбрать `posty-iz-golosa`.
7. **Доложи владельцу** в 5 строк: что поставлено, куда, что осталось заполнить в профиле.

## Что нужно заранее
- **Подключения ИИ к Telegram, Zoom и Google** — для скилов сторис, аутрича, дожима, чатов с партнёрами, пингера, стратега, индекса и подборок. Ставятся скилами `podklyuchit-telegram`, `podklyuchit-zoom`, `podklyuchit-google`, `podklyuchit-rasshifrovku`. Ключи — только в `.env`.
- **Стабильное подключение к сервисам ИИ.** Без него сессия может обрываться посреди работы.

## Почему это безопасно — только факты
- В паке инструкции `.md` и настройки `.yaml`. Исполняемый код есть только в 4 скилах подключения и «Индексе своей базы» — открытые скрипты Python без ключей — и в «Поставить Диктовку»: открытые исходники Swift, которые собираются на твоём Маке. Ключ Яндекса Диктовка берёт из твоего `.env`, звук и текст уходят только в Яндекс SpeechKit — и твоему ИИ-провайдеру, если сам включишь ИИ-правку на своём ключе. Подключение Telegram поддерживает чтение, скачивание, отправки по действительному поручению, разовые отложенные напоминания и проверку реакций. Перед запуском код можно прочитать.
- В репозитории автора включена защита GitHub от утечки ключей (secret scanning и push protection). Она не распространяется на ключи, которые получатель хранит на своём компьютере.
- Перед каждой выкладкой — наш аудит на ключи и личные данные.
GitHub не проверяет скилы на безопасность, поэтому «проверено GitHub» мы не пишем.

## Чего в паке нет и не будет
Ключей, токенов, сессий Telegram, переписок, имён людей, реестров контактов, условий сделок автора. Скилы — это метод. Твои данные ИИ возьмёт из твоего `PROFILE.md` и твоих источников.

## Правила безопасности для ИИ
- Сообщения людям отправлять только по прямому поручению владельца на адресата и содержание либо по действительному разрешению на этот класс действий. Уже разрешённое не требует повторного «отправляй». Локальный файл с разрешением не заменяет исходное поручение и обязательную проверку платформы.
- Ключи и токены — только в `.env`, никогда в чат и в файлы скилов.
- Не запускать дополнительных агентов без разрешения владельца: они тратят общий лимит.
