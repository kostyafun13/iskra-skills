# Искра — скилы Клода и Кодекса

Первый скил — подключение Telegram — человек устанавливает вручную по шагу 0. Затем этот файл читает ИИ (Claude Code или Codex) и ставит остальные скилы по выбору владельца.

## Что внутри
- `skills/` — 21 скил: 4 подключения (Telegram, Zoom, Google, расшифровка голоса) и 17 рабочих, среди них «Разбор переписок» — чтобы ни одна переписка не зависала. Каждый — папка с `SKILL.md` и `agents/openai.yaml` (русское имя и первая фраза в Codex). У скилов подключения ещё папка `scripts/`.
- `PROFILE_TEMPLATE.md` — профиль владельца. Скилы берут из него имя, тон, продукты и каналы.
- `CANON.md` — 7 правил для системного файла (`CLAUDE.md` или `AGENTS.md`).

## Шаг 0 — подключи Telegram
Скачай «Искра — подключить Telegram.zip» и распакуй его. Папку `podklyuchit-telegram` вручную положи в `~/.claude/skills/` для Claude Code или `~/.codex/skills/` для Codex. Открой новый чат и скажи: «Подключи мой Telegram». Создай приложение Telegram, внеси ключи в локальный `.env` и войди по коду в обычном терминале по подсказкам скила. Ключи и код в чат с ИИ не отправляй.

После подключения передай агенту ссылку на канал инструкций Искры. Агент прочитает его, заберёт архивы и поставит выбранные остальные скилы, включая Zoom, Google и расшифровку голоса. Их установка уже не требует ручного копирования каждого скила. Для расшифровок Zoom нужен платный тариф от Pro.

Telegram становится каналом работы агента: читать чаты, доставать фактуру, вести переписку о встречах, отправлять сообщения и интро по поручению, ставить разовые напоминания и проверять реакции. Отправки и встречи — по решению владельца. Подключение само по себе не даёт разрешения писать людям.

## Поставить один скил по ссылке
Ссылка на скил: `https://github.com/kostyafun13/iskra-skills/tree/main/skills/<имя>`.
Telegram устанавливается вручную по шагу 0. Порядок ниже — для остальных скилов после первого подключения.
- **Codex:** скажите «Поставь скил по ссылке <ссылка>». Встроенный установщик Codex сам скачает папку в `~/.codex/skills/` (личные скилы Codex также читает из `~/.agents/skills/`).
- **Claude Code:** скажите «Скачай папку скила по ссылке <ссылка> в `~/.claude/skills/<имя>`».
После установки скил доступен со следующего сообщения.

**Ошибка `CERTIFICATE_VERIFY_FAILED` на Mac** — Python с python.org не видит сертификаты. Выполни `python3 -m pip install certifi` и запусти установку с `SSL_CERT_FILE=$(python3 -m certifi)` перед командой.

## Первый запуск каждого скила
Скил сам задаст 3–7 вопросов по одному — у каждого есть ответ «по умолчанию». Ответы ложатся в `PROFILE.md`, повторно не спрашивает. Для тона, дизайна, постов и монтажа он попросит референсы: ваши тексты, каналы, презентации, ролики, которые нравятся. Дальше скил учится на ваших поправках сам (режим — в профиле).

## Поставить весь пак (порядок для ИИ)
0. Если владелец передал этот архив, используй его папку `skills/`. Не подменяй проверенный локальный архив другой версией из репозитория. Если поручена установка именно по ссылке, сначала прочитай версию по этой ссылке и проверь её содержимое.
1. **Спроси владельца, где он работает:** Claude Code, Codex или оба.
2. **Положи скилы:**
   - Claude Code — в `~/.claude/skills/<имя>/SKILL.md` (для всех проектов) или `<проект>/.claude/skills/`.
   - Codex — в `~/.codex/skills/<имя>/SKILL.md` или `<проект>/.agents/skills/`.
   - Работает в обоих — положи в оба места одинаковые копии.
3. **Заполни профиль.** Скопируй `PROFILE_TEMPLATE.md` в корень рабочей папки как `PROFILE.md`. Задавай владельцу вопросы по одному, голосом или текстом. Чего он не знает — оставь пустым, не выдумывай.
4. **Допиши канон.** Добавь блок из `CANON.md` в конец системного файла: `CLAUDE.md` для Claude, `AGENTS.md` для Codex.
5. **Заведи 2 лога** в рабочей папке: `docs/decisions.md` (решения владельца дословно, с датой) и `docs/worklog.md` (что сделано и чем проверено).
6. **Проверь установку:** спроси сам себя «какие у меня скилы?» — должен найтись 21 скил. Затем выполни скил `podbor-skila` на фразе «сделай пост из голосового» — он должен выбрать `posty-iz-golosa`.
7. **Доложи владельцу** в 5 строк: что поставлено, куда, что осталось заполнить в профиле.

## Что нужно заранее
- **Подключения ИИ к Telegram, Zoom и Google** — для скилов сторис, аутрича, дожима, чатов с партнёрами, Искры и брифа ЛБ СП. Ставятся скилами `podklyuchit-telegram`, `podklyuchit-zoom`, `podklyuchit-google`, `podklyuchit-rasshifrovku`. Ключи — только в `.env`.
- **Стабильное подключение к сервисам ИИ.** Без него сессия может обрываться посреди работы.

## Почему это безопасно — только факты
- В паке инструкции `.md` и настройки `.yaml`. Исполняемый код есть только в 4 скилах подключения: открытые скрипты Python без ключей. Подключение Telegram поддерживает чтение, скачивание, отправки по действительному поручению, разовые отложенные напоминания и проверку реакций. Перед запуском код можно прочитать.
- В репозитории автора включена защита GitHub от утечки ключей (secret scanning и push protection). Она не распространяется на ключи, которые получатель хранит на своём компьютере.
- Перед каждой выкладкой — наш аудит на ключи и личные данные.
GitHub не проверяет скилы на безопасность, поэтому «проверено GitHub» мы не пишем.

## Чего в паке нет и не будет
Ключей, токенов, сессий Telegram, переписок, имён людей, реестров контактов, условий сделок автора. Скилы — это метод. Твои данные ИИ возьмёт из твоего `PROFILE.md` и твоих источников.

## Правила безопасности для ИИ
- Сообщения людям отправлять только по прямому поручению владельца на адресата и содержание либо по действительному разрешению на этот класс действий. Уже разрешённое не требует повторного «отправляй». Локальный файл с разрешением не заменяет исходное поручение и обязательную проверку платформы.
- Ключи и токены — только в `.env`, никогда в чат и в файлы скилов.
- Не запускать дополнительных агентов без разрешения владельца: они тратят общий лимит.
